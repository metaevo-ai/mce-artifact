## STRATEGIES & INSIGHTS

[sai-00001] helpful=3 harmful=0 :: When tagging debt instrument interest rates, distinguish between stated rates (contractual fixed percentage) and effective rates (actual yield considering premiums/discounts). For explicitly stated percentage rates in debt descriptions, 'DebtInstrumentInterestRateStatedPercentage' is typically the correct tag.
[sai-00002] helpful=3 harmful=0 :: When analyzing credit facilities, distinguish between borrowing capacity measurements (maximum/current/remaining capacity) and fee/interest measurements (commitment fees, interest rates). For aggregate amounts representing total available credit under lines of credit, 'LineOfCreditFacilityMaximumBorrowingCapacity' is typically the appropriate tag.
[sai-00003] helpful=2 harmful=0 :: When tagging debt instrument principal amounts, identify monetary values representing the face value or original amount of the debt. For explicit monetary amounts described as principal, face amount, or similar terms in debt descriptions, 'DebtInstrumentFaceAmount' is typically the correct tag. Distinguish these from interest rates, which are percentage values.
[sai-00004] helpful=1 harmful=0 :: For variable-rate debt instruments (e.g., LIBOR, SOFR-based), distinguish between the benchmark rate and the spread/margin. When a percentage value represents an additive margin to a variable benchmark rate (e.g., 'LIBOR plus 1.40%'), use 'DebtInstrumentBasisSpreadOnVariableRate1'. Reserve 'DebtInstrumentInterestRateStatedPercentage' for fixed rates or standalone percentage rates without a variable benchmark component.
[sai-00006] helpful=0 harmful=0 :: When analyzing debt-related monetary values, carefully examine prepositional phrases (e.g., 'pursuant to,' 'under,' 'according to') that directly link a value to a referenced debt instrument. If a value is explicitly connected to a debt instrument's face amount through such contractual language, tag it as DebtInstrumentFaceAmount, even if the numerical value appears discounted. The specific linguistic context overrides general accounting assumptions about carrying amounts versus face amounts.
[sai-00008] helpful=0 harmful=0 :: When tagging financial facilities, identify the primary instrument first before tagging sub-components. If amounts (monetary values or percentages) are presented as metrics 'under' a described facility, tag them according to the primary facility type rather than using more specific sub-component tags. The hierarchical relationship where bank guarantees or borrowings are part of a line of credit facility takes precedence over individual component tagging.
[sai-00010] helpful=0 harmful=0 :: When tagging financial concepts, prioritize standard, specific tags from established taxonomies (like US GAAP XBRL) over broader or more literal tags. For example, 'LongTermDebtFairValue' is the conventional tag for fair value of long-term debt instruments (like Notes), even if a broader tag like 'DebtInstrumentFairValue' seems semantically applicable. Understand hierarchy and common usage in reporting standards to avoid incorrect specificity judgments.
[sai-00011] helpful=0 harmful=0 :: When tagging monetary values from financial statements, prioritize balance sheet classification tags (e.g., CurrentLiabilities, LongTermDebt) over attribute-specific tags (e.g., DebtInstrumentFaceAmount) for values representing balance sheet line items. The primary tag should reflect the item's classification as current/non-current, with detailed attribute tags being supplementary when specifically indicated.
[sai-00012] helpful=0 harmful=0 :: When multiple financial facilities are mentioned together (e.g., revolving credit and term loan facilities), analyze each facility type separately rather than applying uniform tags. Term loan facilities represent debt instruments with fixed principal amounts and should be tagged as DebtInstrumentFaceAmount, while revolving credit facilities with borrowing capacity use LineOfCreditFacilityMaximumBorrowingCapacity. Do not assume all monetary values in the same context belong to the same type of facility.
[sai-00015] helpful=0 harmful=0 :: When tagging credit facility capacities, distinguish between 'current' and 'maximum' borrowing capacity based on temporal context. For amounts explicitly tied to a specific reporting date (e.g., 'As of December 31, 2018'), use 'LineOfCreditFacilityCurrentBorrowingCapacity' as it represents the facility size available at that exact date. Reserve 'maximum' terminology for theoretical upper limits not specifically anchored to a reporting date.
[sai-00017] helpful=1 harmful=0 :: When analyzing letters of credit, distinguish between outstanding obligation amounts and available capacity amounts. For monetary values explicitly described as outstanding letter of credit amounts, 'LettersOfCreditOutstandingAmount' is the appropriate tag, representing actual liabilities rather than available credit under a facility.

[ctx-00005] helpful=5 harmful=0 :: For debt instrument descriptions containing patterns like 'X% Senior Notes' where X is a numerical percentage value, this strongly indicates a fixed stated interest rate and should be tagged as DebtInstrumentInterestRateStatedPercentage.
[ctx-00007] helpful=0 harmful=0 :: Phrases like 'pursuant to [debt instrument],' 'under [debt instrument],' or 'according to [debt instrument]' followed by a monetary value indicate that the value is directly tied to the referenced debt instrument's contractual terms. When such language appears, the monetary value typically represents a portion or aspect of the debt's face amount rather than its carrying amount or proceeds.
[ctx-00009] helpful=3 harmful=1 :: Phrases like 'under this facility,' 'available under the facility,' or 'under the credit agreement' followed by monetary values indicate that all amounts mentioned are attributes of the primary financial facility. When such language appears, tag monetary values according to the primary facility type (e.g., LineOfCredit) rather than using more specific sub-component tags.
[ctx-00013] helpful=0 harmful=0 :: Phrases like 'term loan facility' or 'term loan' followed by a monetary value indicate a debt instrument with a fixed principal amount. When such language appears, the monetary value typically represents the face amount of the debt and should be tagged as DebtInstrumentFaceAmount, distinguishing it from revolving credit facilities which represent borrowing capacity.
[ctx-00014] helpful=0 harmful=0 :: Phrases like 'Warehouse Credit Facility' followed by 'borrowing capacity' indicate a specific type of revolving credit facility used in financial services. When such terminology appears, it strongly confirms the facility should be treated as a line of credit with borrowing capacity measurements rather than a term loan with fixed principal amounts.
[ctx-00016] helpful=0 harmful=0 :: Phrases like 'As of [specific date]' followed by a credit facility amount indicate temporal specificity. When such date-specific language appears with revolving credit facilities, the monetary value typically represents the current borrowing capacity available at that reporting date and should be tagged as 'LineOfCreditFacilityCurrentBorrowingCapacity' rather than maximum capacity.
[ctx-00018] helpful=1 harmful=0 :: Phrases like 'letter of credit issued' or 'outstanding letters of credit' followed by a monetary value indicate an actual obligation amount that should be tagged as 'LettersOfCreditOutstandingAmount' rather than borrowing capacity under a credit facility.
