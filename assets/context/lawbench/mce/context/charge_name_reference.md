# 完整标准罪名参考

## 核心原则
- **必须使用完整的官方标准罪名名称**
- **严禁缩写或遗漏关键词**
- **罪名后不加"罪"字**

## 关键验证规则

1. **每次输出前必须检查**：是否使用了完整的官方标准名称
2. **对于不确定的名称**：参考本表的标准写法
3. **特别注意"、"连接词**：许多罪名包含多个并列要素，必须完整列出
4. **不要省略任何组成部分**：即使看起来是"不言自明"的也不行

## 多罪名场景的罪名列表规则

当案件涉及多个犯罪时：
- 每个罪名都必须使用完整标准名称
- 多个罪名之间用分号分隔
- 顺序不影响评分（但建议按时间或严重程度排列）

### 正确示例
- [罪名]走私国家禁止进出口的货物、物品;行贿
- [罪名]拐卖妇女、儿童;强奸
- [罪名]职务侵占;挪用特定款物

### 错误示例
- [罪名]走私国家禁止进出口货物（缺少"的"和"、物品"）
- [罪名]拐卖妇女儿童（缺少顿号"、"，变成一个新词）
