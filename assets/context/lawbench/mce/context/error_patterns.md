# 训练数据错误模式与修正指南

## 核心错误模式总结

基于训练数据分析，模型在以下方面存在系统性错误：

1. **罪名漏判**：未识别多个犯罪行为
2. **罪名误判**：选择了相似但错误的罪名
3. **罪名名称不准确**：使用了简称或错误名称
4. **罪名多判**：添加了不应存在的额外罪名

---

## 第一部分：常见漏判错误（多罪名案件）

### 模式1：犯罪+自首/另案 → 应包含所有罪名

**错误类型**：只识别主要犯罪，遗漏另案或自首涉及的其他罪名

**案例id=17**：
- 事实：醉驾 + 另案私分国有资产
- **错误预测**：[罪名]危险驾驶<eoa>
- **正确答案**：[罪名]危险驾驶;私分国有资产<eoa>
- **修正规则**：如果事实中提到"另案"、"之前犯罪"、"判决宣告前还有其他罪"，需识别并包含所有罪名

**案例id=75**：
- 事实：盗窃 + 非法持有枪支
- **正确预测**：盗窃;非法持有、私藏枪支、弹药
- **关键点**：两个独立的犯罪行为分别定罪

### 模式2：多个行为人参与的复杂犯罪

**案例id=88**：
- 事实：组织卖淫 + 协助组织卖淫
- **错误预测**：[罪名]组织卖淫<eoa>
- **正确答案**：[罪名]组织、强迫、引诱、容留、介绍卖淫;协助组织卖淫<eoa>
- **修正规则**：根据角色分工，区分"组织者"和"协助者"，分别定罪

### 模式3：犯罪过程中伴随其他违法行为

**案例id=0**：
- 事实：寻衅滋事 + 非法携带枪支、管制刀具
- **错误预测**：寻衅滋事;非法携带枪支、管制刀具危及公共安全
- **正确答案**：寻衅滋事;非法携带枪支、弹药、管制刀具、危险物品危及公共安全
- **修正规则**：非法携带枪支弹药管制刀具的完整罪名包含所有对象

## 第二部分：常见误判错误

### 模式1：过失犯罪识别错误

**案例id=122**（私设电网致人死亡）：
- **错误预测**：[罪名]以危险方法危害公共安全<eoa>
- **正确答案**：[罪名]过失以危险方法危害公共安全<eoa>
- **关键事实**："未设警示标志"、"对可能造成的危险持放任态度但非直接故意"
- **修正规则**：私设电网用于防止动物啃食农田，通常认定为过失而非故意

**案例id=91**（早餐店误放亚硝酸盐）：
- **错误预测**：[罪名]过失致人死亡<eoa>
- **正确答案**：[罪名]过失投放危险物质<eoa>
- **关键事实**："误当作白糖倒入"、"多人中毒"、"危害公共安全"
- **修正规则**：在公共场所/食品中过失投放危险物质→过失投放危险物质

### 模式2：职务犯罪区分错误

**案例id=98**（挪用团费）：
- **错误预测**：[罪名]职务侵占<eoa>
- **正确答案**：[罪名]挪用资金<eoa>
- **关键事实**："挪用"而非"侵占"、"用于归还车贷及个人消费"、"承诺还款"
- **修正规则**：挪用资金vs职务侵占的关键是是否有**非法占有目的**，而非是否归还

**案例id=63**（检疫员出具虚假单据）：
- **错误预测**：[罪名]滥用职权<eoa>
- **正确答案**：[罪名]动植物检疫徇私舞弊<eoa>
- **关键事实**："动物食品检疫员"、"出具虚假单据"、"骗取国家财政补助"
- **修正规则**：特殊身份（检疫人员）+特殊行为（伪造检疫结果）→特定罪名

### 模式3：事故类犯罪区分错误

**案例id=170**（爆破员违规操作）：
- **错误预测**：[罪名]重大责任事故<eoa>
- **正确答案**：[罪名]危险物品肇事<eoa>
- **关键事实**："爆破员"、"乳化炸药"、"电雷管"、"爆破作业"
- **修正规则**：涉及危险物品（炸药、雷管）的作业事故→危险物品肇事

**案例id=102**（铲车撞人致死）：
- **错误预测**：[罪名]重大责任事故<eoa>
- **正确答案**：[罪名]过失致人死亡;破坏生产经营<eoa>
- **关键事实**："驾驶铲车"、"疏忽大意"、"撞倒碾压"、"工地"
- **修正规则**：
  - 过失撞人致死→过失致人死亡
  - 工地生产活动中断→破坏生产经营

### 模式4：罪名名称不完整

**案例id=50**（虚开发票+隐匿会计凭证）：
- **错误预测**：[罪名]虚开增值税专用发票;隐匿会计凭证、会计账簿<eoa>
- **正确答案**：[罪名]隐匿、故意销毁会计凭证、会计帐簿、财务会计报告;虚开增值税专用发票、用于骗取出口退税、抵扣税款发票<eoa>
- **修正规则**：使用完整的标准罪名名称

**案例id=140**（走私木炭）：
- **错误预测**：[罪名]走私国家禁止进出口的货物<eoa>
- **正确答案**：[罪名]走私国家禁止进出口的货物、物品<eoa>
- **修正规则**：注意"货物、物品"的完整表述

**案例id=66**（伪造房产证）：
- **错误预测**：[罪名]伪造国家机关证件<eoa>
- **正确答案**：[罪名]伪造、变造、买卖国家机关公文、证件、印章<eoa>
- **修正规则**：使用完整罪名，伪造国家机关证件包含在"公文、证件、印章"中

**案例id=158**（收购赃车）：
- **错误预测**：[罪名]盗窃;掩饰、隐瞒犯罪所得<eoa>
- **正确答案**：[罪名]盗窃;掩饰、隐瞒犯罪所得、犯罪所得收益<eoa>
- **修正规则**：使用完整罪名"掩饰、隐瞒犯罪所得、犯罪所得收益"

## 第三部分：常见多判错误（不应存在的罪名）

### 模式1：容留场景中的持有毒品不单独定罪

**案例id=171**：
- **错误预测**：[罪名]容留他人吸毒;非法持有毒品<eoa>
- **正确答案**：[罪名]容留他人吸毒<eoa>
- **关键事实**：容留他人吸毒时被查获持有毒品2.01克
- **修正规则**：在容留他人吸毒现场查获的少量毒品，通常不单独认定为非法持有毒品罪

### 模式2：行贿对象识别错误

**案例id=13**（给拆迁工作人员送钱）：
- **错误预测**：[罪名]对非国家工作人员行贿<eoa>
- **正确答案**：[罪名]行贿<eoa>
- **关键事实**："茂湛铁路有限责任公司负责吴川路段征地拆迁工作"→国有公司人员=国家工作人员
- **修正规则**：国有公司、企业中从事公务的人员属于国家工作人员

**案例id=148**（给医院院长回扣）：
- **错误预测**：[罪名]对单位行贿<eoa>
- **正确答案**：[罪名]行贿<eoa>
- **关键事实**："钦州市第一人民医院院长陈某"→国家工作人员
- **修正规则**：医院院长是国家工作人员，向其行贿→行贿

### 模式3：诈骗vs贷款诈骗识别错误

**案例id=175**（伪造土地证贷款）：
- **错误预测**：[罪名]诈骗;骗取贷款<eoa>
- **正确答案**：[罪名]贷款诈骗<eoa>
- **关键事实**："利用伪造的国有土地使用证"、"信用社借款"、"无力偿还"
- **修正规则**：伪造证明文件诈骗贷款，且无偿还能力→贷款诈骗

## 第四部分：特殊罪名识别规则

### 规则1：过失犯罪关键词识别

以下场景通常是**过失**犯罪：
- 农村私设电网防止动物→过失以危险方法危害公共安全
- 驾驶时疏忽大意→过失致人死亡
- 误放危险物质→过失投放危险物质

### 规则2：特殊身份+特殊行为→特定罪名

- 检疫员+伪造检疫结果→动植物检疫徇私舞弊
- 爆破员+危险物品→危险物品肇事
- 协警+帮助犯罪分子→帮助犯罪分子逃避处罚

### 规则3：多罪名组合识别

- 工地过失撞人→过失致人死亡;破坏生产经营
- 招嫖+协助→组织卖淫;协助组织卖淫
- 醉驾+另案→危险驾驶;其他罪名

## 第六部分：多罪名检测清单

当分析案件事实时，检查是否存在以下情况：

1. **多个犯罪行为**：
   - 不同时间实施的犯罪
   - 不同地点实施的犯罪
   - 针对不同对象的犯罪

2. **犯罪+行政处罚/另案**：
   - 是否提到"另案处理"
   - 是否提到"判决宣告前还有其他罪"
   - 是否提到"之前犯罪"

3. **共同犯罪分工**：
   - 组织者vs协助者
   - 主犯vs从犯
   - 不同角色不同定罪

4. **犯罪过程中伴随违法行为**：
   - 实施犯罪时携带违禁品
   - 犯罪后毁灭证据
   - 犯罪中使用虚假文件

## 输出格式检查清单

在输出罪名时，检查以下项目：

- [ ] 罪名后不加"罪"字
- [ ] 使用完整的标准罪名
- [ ] 多个罪名用分号分隔
- [ ] 罪名顺序正确（无要求，顺序无关）
- [ ] 覆盖了所有独立犯罪行为
- [ ] 未添加不应存在的额外罪名
