# 多罪名检测指南

## 核心原则
**多罪名是默认假设**：每个案件都应首先假设可能存在多个犯罪，只在证据明确指向单一犯罪时才接受单罪名。

## 多罪名检测触发器

### 1. 时间标记
- 不同年份/月份出现 → 很可能多个犯罪
- "2013年...2014年..." → 分别分析每年的行为
- "同年x月x日" → 可能是同案的不同犯罪

### 2. 编号结构
- "（一）...（二）..." → 每个编号是一个独立犯罪
- "1. ... 2. ..." → 每个数字是一个独立犯罪
- "首先...其次...最后..." → 可能多个犯罪

### 3. 行为标记词
- "另查明" → 额外的犯罪事实
- "另案处理" → 涉及其他犯罪（但需聚焦本案被告人的行为）
- "判决宣告前" → 存在未判决的其他犯罪
- "在...期间" → 时间跨度内可能有多个行为

### 4. 罪名并列标记
- "以...追究其刑事责任" → 多个罪名
- "分别触犯...及..." → 多个罪名
- "一人犯数罪" → 明确多罪名
- "应当数罪并罚" → 明确多罪名

### 5. 关键动词模式
- "持刀拦截" → 可能涉及抢劫、劫持
- "冒充" → 可能涉及招摇撞骗、诈骗
- "伪造" → 可能涉及伪造证件、诈骗
- "容留" → 可能同时涉及毒品犯罪

## 多罪名检测流程

### 第一步：全面扫描
阅读整个案件描述，标记所有可能的犯罪行为：
1. 列出每个独立的行为
2. 标记每个行为的时间、地点、对象
3. 识别是否有明确的"另案"或"数罪"提示

### 第二步：罪名匹配
对每个行为分别匹配罪名：
1. 行为1 → 罪名A
2. 行为2 → 罪名B
3. 不要因为已经找到一个罪名就停止

### 第三步：吸收检查
检查是否存在罪名吸收关系：
- 盗窃过程中使用暴力 → 抢劫（吸收盗窃）
- 伤害过程中猥亵 → 可能并罚（除非严重程度足够吸收）

### 第四步：遗漏检查
对照常见遗漏模式：
- 是否有隐藏的盗窃/抢劫？
- 是否有职务犯罪？
- 是否有妨害公务？
- 是否有毒品相关？

## 特殊案例模式

### 案例1：编号结构（（一）（二））
**模式**：案件事实中出现"（一）"和"（二）"等编号
**检测方法**：每个编号对应一个独立犯罪
**示例**：ID 190（放火;抢劫）
- （一）2015年放火 → 放火罪
- （二）2007年抢劫 → 抢劫罪
**输出**：放火;抢劫

### 案例2：另案处理
**模式**：出现"另案处理"但本案被告仍有其他行为
**检测方法**：不要因他人另案处理而忽略本案被告的犯罪
**示例**：ID 175（贷款诈骗）
- 诈骗刘某某（个人）→ 贷款诈骗
- 注意：可能需要根据具体证据决定是否并罚

### 案例3：时间跨度内的多个行为
**模式**：同一时间段内实施多个不同类型犯罪
**检测方法**：分别分析每个行为
**示例**：ID 46（盗窃;非法狩猎）
- 盗窃桂花树 → 盗窃罪
- 捕获黑水鸡 → 非法狩猎罪

### 案例4：暴力犯罪+财产犯罪
**模式**：先实施暴力，再窃取财物
**检测方法**：检查是否构成抢劫（暴力吸收盗窃）
**示例**：ID 57（劫持船只、汽车;抢劫;盗窃）
- 持刀拦截货车 → 劫持船只、汽车
- 抢劫现金 → 抢劫
- 盗窃财物 → 盗窃
**关键**：如果暴力行为与财产取得有直接因果关系，可能构成抢劫

### 案例5：性犯罪+暴力
**模式**：强奸过程中有猥亵、暴力行为
**检测方法**：检查是否需要并罚
**示例**：ID 79（强奸;侮辱）
- 强奸行为 → 强奸罪
- 猥亵、暴力行为 → 侮辱罪（或强制猥亵，需根据证据）

### 案例6：职务犯罪隐藏
**模式**：利用职务便利实施犯罪
**检测方法**：检查是否有职务侵占、挪用资金等
**示例**：ID 143（单位行贿;利用影响力受贿）
- 通过影响力谋利 → 利用影响力受贿
- 为单位谋利行贿 → 单位行贿

## 常见错误与修正

### 错误1：遗漏次要犯罪
**错误表现**：只识别主要罪名，忽略次要犯罪
**修正方法**：对每个行为独立匹配罪名，不要主观判断"哪个更重要"

### 错误2：错误合并罪名
**错误表现**：将两个独立犯罪合并为一个罪名
**修正方法**：确定犯罪之间是否有因果关系或吸收关系

### 错误3：忽略罪名完整性
**错误表现**：使用缩写罪名
**修正方法**：使用完整标准名称（参考charge_name_reference.md）

## 快速检查清单

对每个案件，务必检查：

- [ ] 是否存在编号结构（（一）（二）等）？
- [ ] 是否存在时间标记（不同年份/月份）？
- [ ] 是否提到"另案处理"或"数罪"？
- [ ] 是否存在暴力+财产的组合？
- [ ] 是否存在职务犯罪要素？
- [ ] 是否存在性犯罪+暴力的组合？
- [ ] 是否存在毒品/野生动物相关犯罪？
- [ ] 每个犯罪行为都使用了完整标准罪名吗？
